

## Описание проекта
Цель проекта — **обнаружение загрязнений на экранах банкоматов** с помощью компьютерного зрения.

Архитектура:
1. **Детекция банкомата** (`yolo11n.pt`)
   - Используется для локализации банкомата на изображении.
   - Детекция и кроп выполняются в `detection.py`.

2. **Классификация состояния банкомата** (`yolo11n-cls.pt`)
   - Классифицирует вырезанный банкомат как чистый или грязный.
   - Классификация реализована в `classification.py`.
   
## Почему YOLO?

Модель YOLO (You Only Look Once) выбрана по следующим причинам:

- **End-to-end подход**: объединение детекции и классификации в единой архитектуре.
- **Высокая скорость работы**: особенно важна для real-time задач.
- **Точность на малых объектах**: хорошо работает с изображениями.

## Roboflow

Разметка изображений, аугментации и экспорт датасета выполнялись с помощью платформы **[Roboflow](https://roboflow.com)**:

- Использовали удобный интерфейс для ручной разметки экранов.
- Применяли автоматические аугментации.
- Экспорт в формат YOLOv11.

Датасеты получены с помощью скриптов `import_dataset_detection.py` и `import_dataset_classification.py`.

```

├── yolo_classification_checkpoints/   # Чекпоинты классификации

│
├── yolo11n.pt                         # Веса YOLO модели детекции
├── yolo11n-cls.pt                     # Веса YOLO классификатора

```

## Описание датасета
В проекте используется **пользовательский датасет банкоматов**, размеченный на 2 класса:
```
dataset/
├── clean/    # Чистые банкоматы
├── dirty/    # Загрязнённые банкоматы
```
Импорт и разметка — скрипты:
- `import_dataset_classification.py`
- `split_dirty_clean.py`

## Как запустить
### 1. Установка зависимостей
```bash
pip install torch torchvision ultralytics opencv-python matplotlib tqdm scikit-learn
```

### 2. Детекция 
```bash
python detection.py
```

### 3. Классификация 
```bash
python classification.py
```

### 4. Тестирование модели классификации
```bash
python test_model.py
```
