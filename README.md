
## 📌 Описание проекта
Проект предназначен для **автоматического определения загрязнений на экранах банкоматов** на основе изображений.

В решении используется:
- **YOLOv8** — для детекции банкоматов на изображениях
- **YOLOv8 Classification** — для классификации состояния экрана (чистый / грязный)

---

## 📂 Структура репозитория
```
├── detect_atm_and_crop.py                # Детекция банкоматов и обрезка экрана
├── classification.py                    # Классификация "чистый / грязный"
├── detection.py                         # Запуск детекции банкоматов
├── test_model.py                        # Тестирование модели классификации
├── import_dataset.py                    # Загрузка и разметка датасета
├── import_dataset_kaggle.py             # Загрузка датасета с Kaggle
├── split_dirty_clean.py                 # Сплит датасета по классам
├── yolo11n.pt                           # Чекпойнт модели детекции
├── yolo11n-cls.pt                       # Чекпойнт модели классификации
├── runs/                                # Результаты работы моделей
├── yolo_classification_checkpoints/    # Чекпойнты классификатора
```

---

## 📊 Описание датасета
В проекте используется **пользовательский датасет изображений банкоматов** с реальными и синтетическими загрязнениями.

Структура данных для классификации:
```
dataset/
├── clean/      # Изображения чистых экранов
├── dirty/      # Изображения загрязнённых экранов
```

✅ Данные для обучения загружались вручную и с Kaggle, далее были размечены скриптами `import_dataset.py` и `split_dirty_clean.py`.

## 🚀 Как запустить
### 1. Установить зависимости
```bash
pip install torch torchvision ultralytics opencv-python matplotlib tqdm scikit-learn
```

### 2. Запуск детекции банкомата
```bash
python detect_atm_and_crop.py
```

### 3. Классификация состояния экрана
```bash
python classification.py
```

### 4. Тестирование модели
```bash
python test_model.py
```
